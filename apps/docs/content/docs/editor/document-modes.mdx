## What to notice

| Mode         | Result                             | Use it when                                       |
| ------------ | ---------------------------------- | ------------------------------------------------- |
| `editing`    | The text changes directly.         | Changes should become part of the document.       |
| `suggesting` | The edit becomes a tracked change. | Another person should review the proposed change. |
| `viewing`    | The edit is blocked.               | A person should read without changing the DOCX.   |

Modes change Editor behavior in the browser. They do not decide who can open or save the document.

## Set the starting mode

Pass the starting mode when you create the Editor:

```ts
const superdoc = new SuperDoc({
  selector: '#editor',
  document: '/sample.docx',
  documentMode: 'suggesting',
  user: { name: 'Jordan Lee', email: 'jordan@example.com' },
});
```

After `onReady`, call `superdoc.setDocumentMode('viewing')` to change modes without remounting. Set `user` from your
authenticated application so exported tracked changes keep the correct author.

## Choose what viewers see

Viewing stays read-only. Add only the review information the person needs:

| Viewer experience          | Add to `Config`                                |
| -------------------------- | ---------------------------------------------- |
| Document without review UI | Nothing                                        |
| Comments only              | `comments: { visible: true }`                  |
| Tracked-change markup only | `modules: { trackChanges: { visible: true } }` |
| Comments and change markup | Combine both settings                          |

This example shows comments and tracked-change markup:

```ts
new SuperDoc({
  selector: '#editor',
  document: '/sample.docx',
  documentMode: 'viewing',
  comments: { visible: true },
  modules: {
    trackChanges: { visible: true, mode: 'review' },
  },
});
```

Use `modules.trackChanges.mode` to choose how changes render: `original` shows the document before proposals, `review`
shows markup, and `final` shows the proposed result without markup. Use `setTrackedChangesPreferences()` to change that
display after the Editor is ready.

Hiding comments or tracked changes does not remove them from the DOCX.
