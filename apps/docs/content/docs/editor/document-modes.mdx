Switch modes, then replace `30 days` with `60 days`. The same edit changes the text, creates a tracked change, or is
blocked.

## Compare the three modes

<EditorDemo fixture='/fixtures/document-modes.docx' preset='document-modes' title='Try document modes' />

| Mode         | Result                             | Use it when                                       |
| ------------ | ---------------------------------- | ------------------------------------------------- |
| `editing`    | The text changes directly.         | Changes should become part of the document.       |
| `suggesting` | The edit becomes a tracked change. | Another person should review the proposed change. |
| `viewing`    | The edit is blocked.               | A person should read without changing the DOCX.   |

Modes change Editor behavior in the browser. They do not decide who can open or save the document.

## Set the starting mode

Pass the starting mode when you create the Editor:

```ts
const superdoc = new SuperDoc({
  selector: '#editor',
  document: '/sample.docx',
  documentMode: 'suggesting',
});
```

After `onReady`, call `superdoc.setDocumentMode('viewing')` to change modes without remounting.

## Choose what viewers see

Viewing stays read-only. Use `viewing` to choose which review information appears:

```ts
const superdoc = new SuperDoc({
  selector: '#editor',
  document: '/sample.docx',
  documentMode: 'viewing',
  viewing: {
    comments: true,
    trackedChanges: 'markup',
  },
});
```

| `trackedChanges` | Viewer sees                       |
| ---------------- | --------------------------------- |
| `original`       | The document before proposals.    |
| `markup`         | Proposals with change marks.      |
| `final`          | Proposals applied without markup. |

`original` is the default. Comments are hidden by default.

Change either option after `onReady`. Omitted options keep their current values:

```ts
superdoc.setViewingOptions({
  trackedChanges: 'final',
});
```

Hiding comments or tracked changes does not remove them from the DOCX.
