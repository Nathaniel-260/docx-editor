<Callout variant='warning' title='Use the new React package for v2'>
  `@superdoc-dev/react` is the v1 wrapper. The stable v2 wrapper is `@superdoc/react`.
</Callout>

Use `SuperDocEditor` for the Editor lifecycle. Pass startup configuration as props, and use its ref when your application
needs an imperative method such as `export()`.

## 1. Create a React project

```bash
pnpm create vite@latest superdoc-react --template react-ts
cd superdoc-react
pnpm add @superdoc/react
```

## 2. Prepare a document

Download the sample DOCX and save it as `public/sample.docx`:

<FileDownload
  href='/fixtures/sample-nda.docx'
  label='Download the sample document'
  description='Synthetic agreement with headings, paragraphs, and a list'
  fileType='DOCX'
/>

Vite serves files in `public` from the root of the development server, so SuperDoc can load it from `/sample.docx`.

## 3. Create the Editor component

Replace `src/App.tsx` with this component:

<include>../../../../../../examples/react/src/App.tsx</include>

The complete project is available at [go.superdoc.dev/examples/react](https://go.superdoc.dev/examples/react).

Remove the starter `App.css` import and replace the contents of `src/index.css` with:

```css
html,
body,
#root {
  min-height: 100%;
  margin: 0;
}
```

`SuperDocEditor` creates the mount container and destroys the Editor when React removes the component. `onReady` enables
export only after the DOCX opens. `getInstance()` exposes the running Editor for export and other runtime methods.

## 4. Edit and export

Run `pnpm dev` and open the printed URL. Replace a word in the document, then select **Export DOCX**. The browser should
download `sample-edited.docx`.

<Callout variant='success' title='Verification target'>
  Reopen the exported file in Word or SuperDoc. Your edit should be present, and the document formatting should be
  unchanged.
</Callout>

## Add React-owned controls

The component above uses SuperDoc's built-in interface. When React should render your toolbar or panels, follow the
[React custom UI setup](/editor/custom-ui/react-setup). That path installs `superdoc` and uses its `superdoc/ui/react`
provider and hooks.

Or learn how to [load and save user documents](/editor/load-and-save-documents).
