Continue with the sample NDA from the [Editor quickstart](/editor/quickstart). In a production application, the DOCX
usually comes from your storage through an authenticated API.

## Connect the Editor to your storage

Fetch the sample NDA, open it as a DOCX, and send the edited file back to the same endpoint.

For Vanilla, replace the Quickstart controls with a save action and status:

```html
<button id="save-docx" type="button" disabled>Save DOCX</button>
<output id="document-status">Opening…</output>
<div id="editor"></div>
```

Before running the example, expose `/api/documents/sample-nda` from your backend:

| Request | Your endpoint must                                                          |
| ------- | --------------------------------------------------------------------------- |
| `GET`   | Return the current DOCX bytes                                               |
| `PUT`   | Store the request body and return a success status after the write finishes |

The Quickstart Vite project does not create this endpoint. Point the example at your application API, or add a local
endpoint that follows this contract.

The endpoint can read from a database, object store, or bucket. Your application owns its authentication and storage
rules. SuperDoc opens the `Blob` and exports the edited DOCX; it does not store the file.

`export()` confirms that SuperDoc produced a DOCX. Show a saved state only after the `PUT` request succeeds.

## Open or save another way

| Task                           | Use                                                        |
| ------------------------------ | ---------------------------------------------------------- |
| Open a public or signed URL    | `document: url`                                            |
| Open a file selected by a user | `document: file`                                           |
| Switch the mounted Editor      | `await superdoc.replaceFile(nextDocx)`                     |
| Download instead of saving     | `await superdoc.export({ exportedName: 'sample-edited' })` |

A URL from another origin must allow the browser request through CORS. Fetch the file yourself and pass a `Blob` when
the request needs custom headers.

## Verify the round trip

Edit the NDA, save it, and reload the page. Confirm that the edit is still present. Reopen the saved DOCX in Word when
you also need to check its formatting, comments, or tracked changes.
