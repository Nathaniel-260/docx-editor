Follow this guide from top to bottom. You will open a sample agreement, change its text, and export a new DOCX.

## 1. Create a project

Create a Vite project and install SuperDoc:

```bash
pnpm create vite@latest superdoc-quickstart --template vanilla-ts
cd superdoc-quickstart
pnpm add superdoc
```

The `latest` tag installs SuperDoc v2. Pin the resolved version before shipping so upgrades stay deliberate.

## 2. Add the sample document

Download the sample and save it as `public/sample.docx`:

Vite serves `public/sample.docx` at `/sample.docx`.

## 3. Add the page

Replace the body of `index.html` with an export button and an Editor mount point. Keep the existing module script:

```html
<button id="export-docx" type="button" disabled>Export DOCX</button>
<div id="editor"></div>
```

## 4. Open the document

Replace the contents of `src/main.ts`:

<include>../../../../../examples/vanilla/src/main.ts</include>

Run the project:

```bash
pnpm dev
```

Open the printed URL. The agreement should appear, and **Export DOCX** should become enabled. That button stays disabled
until `onReady` confirms that the document is open.

## 5. Make an edit and export

Replace a word in the agreement, then select **Export DOCX**. The browser downloads `sample-edited.docx`.

<Callout variant='success' title='Check the exported document'>
  Reopen `sample-edited.docx` in Word or SuperDoc. Confirm that your edit is present and that the heading, paragraphs,
  and list still have their original formatting.
</Callout>

## What just happened

- `selector` chose where the Editor mounted.
- `document` gave the browser a DOCX URL to open.
- `onReady` marked the first safe moment to enable document actions.
- `export()` created the edited DOCX and triggered the download.

If the document does not appear, check the `onException` message in the browser console. It reports startup failures
instead of leaving an unexplained empty mount point.

The complete project is available at [go.superdoc.dev/examples/vanilla](https://go.superdoc.dev/examples/vanilla).
